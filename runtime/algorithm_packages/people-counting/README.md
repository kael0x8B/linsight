# 人员统计 1.0.0

统计单路摄像头指定矩形区域内的当前可见人数；不是累计人流量，不识别员工身份，不生成离岗告警。默认全画面、人体中心落入区域计数，可选人体底部作为位置判断点。人员模型的 NMS 负责单帧检测框去重，本包不把跟踪器补帧当作实际观察。

仅依赖 `person` 人员检测模型，无人员库和人脸模型依赖。`personConfidence` 过滤低置信度结果，`showPersonBoxes` 控制人体框默认显示。参数 `roi` 可在配置界面框选。

每个有效推理帧都输出 `people_count` 区域统计对象，包括 `observedCount`、`observedAtMillis` 和 `countScope=CAMERA_ROI`，无人时明确输出 0。显示文本为“当前人数：N 人”，统计结果不显示置信度百分比；所有输出 `eventCandidate=false`。`outputMode=STATISTICS` 是配置界面的统计模式提示，隐藏告警配置；任务不绑定告警规则。

没有新画面或推理失败时不产生伪造的 0 人结果；使用平台现有画面过期、离线和任务错误状态。计数与画面使用相同源时间戳。三路画面分别显示人数，不直接相加，不承诺跨镜头去重。遮挡、小目标和低清画面可能漏检，需用原始码流人工标注验证。

现场验证见 `docs/PEOPLE_COUNTING_20260910.md`。前一轮员工离岗需求已取消，历史包及证据仅保留追溯。
