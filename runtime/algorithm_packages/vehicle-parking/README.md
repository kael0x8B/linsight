# 车辆违停检测

SDK 1.0 算法包；依赖具备 car / truck / bus 类别的 OBJECT_DETECTION 模型，支持 ONNX / RKNN。当前平台 COCO RK3566 模型可复用。

上传 ZIP、发布，在网关添加算法并选择摄像头。先在“告警条件”绘制禁停区域。默认规则：5 帧中 3 帧，车辆中心相对停车位置移动不超过画面的 0.02，连续满足 120 秒后产生 VEHICLE_STATIONARY 事件。

区域外车辆不告警；经过或短停未达时长不告警；移动超过容差重新计时；丢失候选会中断持续确认。长时间遮挡、镜头晃动、轨迹切换可能影响计时，需结合现场视角验证。

框上的“小汽车 / 货车 / 客车”是检测结果，不表示已经违停。识别阈值在“识别参数”设置，禁停区域、容差、停留时间和告警间隔在“告警条件”设置。

算法包不含模型权重。SDK 说明见 SDK.md。发布本包不代表现场效果已经验收。
