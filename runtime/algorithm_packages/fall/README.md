# 跌倒检测

SDK 1.0 算法包；依赖具备 `fall` 类别的 OBJECT_DETECTION 模型，支持 ONNX / RKNN。
当前平台兼容 SafetyVision RK3566 模型。不会把普通人员框、长宽比或站立人员直接当作跌倒。

上传 ZIP、发布，在网关添加本算法，选择摄像头和模型。默认告警规则为 5 帧中 3 帧、持续 2 秒，告警间隔 60 秒。阈值在“识别参数”设置，区域与连续确认在“告警条件”设置。

默认覆盖全画面，部署时请按现场修改区域。输出“疑似跌倒”只是候选，规则确认后才产生 FALL 事件。
现场准确率需要用真实跌倒、正常活动与遮挡样本验证，本包不自带现场验收结论。SDK 接口见 SDK.md。
