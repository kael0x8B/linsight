# 人员离岗检测 1.0.0

复用 Person Detector + Tracker + COUNT_BELOW。按指定岗位区域内的人员数量判断，不提供具体人员身份核验。

在告警条件中绘制岗位多边形，选择目标底部或中心，设置最低在岗人数、连续确认帧数、离岗持续时间、恢复确认时间及生效时段。默认少于 1 人，3/5 帧确认后持续 60 秒告警，返岗持续 5 秒恢复。人数不足期间只产生一次活动事件。

包仅过滤人员与置信度，不自行计时、不伪造人员框。空检测列表必须继续交给规则引擎，才能检测无人岗位。摄像头断流或模型异常不是无人观测。不同岗位请分别配置任务与区域。

使用真实连续视频验证在岗、短暂离开、持续离岗、返岗、旁人经过、遮挡与断流；启动成功不等于效果验收。默认全画面必须按现场岗位范围调整。
