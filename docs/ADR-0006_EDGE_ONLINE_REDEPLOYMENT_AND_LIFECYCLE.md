# ADR-0006：Edge Agent 在线重部署与节点生命周期闭环

- 状态：Accepted
- 日期：2026-09-04
- 范围：Node 领域、Edge Agent、节点部署 UI

## 背景

签名 `tar.gz` 升级适合正式发布，但现场联调还需要把控制面当前 Runtime/Agent 源码直接重新部署到
已接管节点。原 SSH 部署输出虽有持久化字段，正在运行的后端版本和远端进程缓冲仍可能让页面只显示
阶段而看不到实时输出。节点列表也缺少重启、关机和安全删除入口。

## 决策

1. 保留签名升级包与回滚命令；新增“在线升级（重新部署）”，复用一次性 SSH 预检、主机指纹固定、
   内存凭据和异步部署记录。已存在节点沿用原编码和长期凭据，不再生成无用 bootstrap token。
2. 每次在线重部署记录 `operation_type=REDEPLOY`、源码包 SHA256、阶段、进度、脱敏输出、结果与诊断 ID；
   成功必须同时通过 Runtime 本机健康检查、systemd 服务检查和本次部署后的新鲜心跳。
3. SSH 命令用行缓冲执行，阶段和输出最多保留最新 256 KiB；前端按 1.5 秒有界轮询并自动跟随末尾，
   不建立无限推送全量日志的 WebSocket。
4. 重启与关机使用既有耐久节点命令，类型分别为 `RESTART_NODE`、`SHUTDOWN_NODE`。Agent 只向
   `/run/linsight/node-power-request` 写入固定动作；root systemd Path/Service 校验动作后延迟执行
   `reboot` 或 `poweroff`。Agent 不获得通用 sudo 权限。
5. 删除采用逻辑删除，只允许离线、无关联任务且无活动命令的节点；节点凭据随即失效，部署、升级、
   命令和日志历史继续保留审计。

## 兼容与回滚

旧 Agent 会忽略不了解的生命周期命令并上报失败，因此现有节点应先执行一次在线重部署或安装包含
该能力的签名版本。回滚管理端和控制面即可隐藏新入口；撤销 `ai-video:node:operate` 与
`ai-video:node:delete` 权限可立即禁止操作。节点上的 systemd Path 可停用，既有心跳、任务、预览、
日志、签名升级与回滚协议不受影响。

## 验收

- 部署创建后立即出现队列日志，远端 stdout/stderr 分段持久化并在页面持续增长。
- 在线重部署保留节点 ID/编码/凭据，完成后出现新源码指纹版本和新鲜心跳。
- 生命周期命令具备权限、幂等键、状态上报和固定动作白名单。
- 在线节点、有关联任务或有活动命令时删除被服务端拒绝。

## 2026-09-06 审查修正

- SSH 预检核对远端凭据的节点 ID、租户与摘要；IP/主机名仅是连接属性。实际 sudo 权限、Ubuntu/Debian + systemd、Python 3.12/3.13、可用内存与磁盘均参与门禁。切换前从远端验证控制面 ping。
- 同租户的节点/已验证主机与节点编码采用数据库行锁串行预留；部署、签名升级和主机操作共用占用检查。部署请求携带幂等 ID，远端另有 flock。
- 当前单控制面进程启动时，将其他执行者遗留的 QUEUED/RUNNING 标记为 INTERRUPTED，凭据不持久化、不自动重放。队列拒绝写入终态；bootstrap 在执行器真正开始后才签发。并行控制面滚动运行尚不在此 SSH 执行器部署方式的支持范围内。
- 完整源码部署切换前，在 root 独占的 `/var/lib/linsight-deployments/<id>` 保存代码、venv、环境、服务和签名链接快照；安装失败立即恢复，SSH/控制面丢失由 300 秒 systemd 定时任务恢复。只有控制面确认目标版本新心跳后才提交快照并撤销定时恢复。
- “恢复完整部署”需要 SSH 预检且恢复上述快照；“回滚签名 Agent”只操作签名版本目录，不混用两套 previous。
- 签名升级的目录切换仅为 AWAITING_ACTIVATION；人工重启后进入 VERIFYING，目标版本新鲜心跳且 Runtime UP 才 SUCCEEDED。启动器等待健康回执最多 120 秒，崩溃/超时恢复前一签名版本或源码基线；旧启动器必须先在线重部署才能启用签名升级。
- 源码版本使用稳定打包后的 `source-<SHA256前12位>`，文件时间戳不参与版本变化。部署记录区分原版本、目标版本、包摘要；历史未记录的目标版本保留未知，不能倒推其已经做过版本验证。
- 日志采集状态区分 LEGACY/COLLECTING/COMPLETE/FAILED，并标注尾部截断。历史列表分页且不返回日志正文，详情读取 SSH 输出。运行日志用 ID 增量与固定快照，历史页不自动漂移。

修复和验证证据见 [EDGE_NODE_MODULE_FIXES_20260906.md](EDGE_NODE_MODULE_FIXES_20260906.md)。隔离测试不替代现场升级、真实关机及现场恢复验收。
