## 复现与证据

在 `frontend` 目录执行，密码通过环境变量提供，不写入脚本或验证报告：

```sh
LINSIGHT_UI_E2E=1 LINSIGHT_E2E_PASSWORD='<本地登录密码>' node tests/e2e/ui-layout.mjs
node tests/e2e/task-evaluation.mjs
```

布局脚本仅允许 localhost/127.0.0.1，拦截所有 AI-video 非 GET 请求，使用本地已有目录数据；算法用例需要“人员闯入”预置算法。错误恢复用例只替换一次浏览器响应，不改变服务端。

截图和机器可读结果生成在 `output/ui-ux/`，其中 `results.json` 记录 28 项断言的几何数据与结果；该目录为本地忽略产物。生产构建命令为 `bash scripts/build-gateway-console.sh`。现场节点未部署本轮网页，验证未启动、停止或更新现场任务。
