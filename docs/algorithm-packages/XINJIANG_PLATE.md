# 新疆车牌独立算法包

新增「厂区车辆识别（新疆优化）」1.0.0，编码 `xinjiang-plate-package`，与旧车牌算法并存。配置位置仍为网关的「添加识别算法」。模型权重保持独立管理，不因算法包发布而替换旧任务绑定。

完整安装、默认策略、验收口径和恢复步骤见 [包说明](../../runtime/algorithm_packages/xinjiang-plate/README.md)。当前状态为代码与工程验证阶段，已在本机平台上传并发布，尚未部署到现场盒子，未承诺识别准确率提升。

本包需要通用运行能力 `plate-ocr-evidence-v1`。仅支持旧 SDK 1.0、但未报告此能力的盒子不能运行完整候选比较方案，应在前端预检和 Runtime 启动检查中被拒绝。该接口补齐以后，后续新疆策略更新通过 ZIP 发布，旧包、旧任务继续固定其原版本。

职责：algorithm 拥有地区排序和号码确认策略；Runtime 提供模型原始观测、裁剪与物理轨迹；model 拥有固定权重/格式；task 保存精确包、模型与参数版本；event 沿用既有候选、身份去重和投递机制。参数是包自有 `parameters.algorithm`，不会进入旧车牌全局配置。

验收必须包含：旧解码输出一致、旧车牌/其他算法回归、强外省证据保护、主体低分拒绝、重复/缺失/过期帧、两车隔离、单图不确认、事件去重、旧 Runtime/不兼容模型拒绝、包重装/重启状态隔离，以及真实新疆/外省录像对比。算法回退和 Runtime 应用回退分别验证。
