## 判定口径

| 场景 | 输出 |
| --- | --- |
| 本人脸部多帧匹配且位于岗位 | 本人在岗 |
| 无人或连续确认是其他人 | 本人未在区域内，按规则持续确认离岗 |
| 背对、低清、遮挡、灰区相似度、参考失效 | 身份待确认，暂停告警确认和恢复 |
| 本人已核验、人体保持连续一对一关联 | 可短时保留身份，默认 10 秒 |
| 人体消失、交叉歧义、观测间隔超过 3 秒或保留过期 | 丢弃身份关联并重新核验 |

默认匹配相似度 0.6、明确非本人上限 0.3、3/5 帧身份确认。默认告警为 3/5 帧后持续 60 秒，恢复确认 5 秒。此为工程初值，需用实际正反样本调参。未实现活体核验。

岗位矩形在“识别参数”设置；“告警条件”的区域默认保持全画面，用来接收岗位状态。输出框表示岗位区域，不是假造的人体框。未知状态不算返岗，不能把活动告警自动关闭。
