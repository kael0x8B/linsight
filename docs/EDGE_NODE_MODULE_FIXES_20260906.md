## 版本确实参与流程

- 源码部署：稳定 ZIP 的 SHA256 前 12 位构成 `source-xxxxxxxxxxxx`；归档固定文件排序和时间戳。文件 mtime 变化不会变版本，包内容变化会变版本。
- 签名包：目标版本参与 HMAC 校验和不可变版本目录选择；同版本不同内容拒绝覆盖；不能用报告中的其他版本替换请求目标。
- 验收：源码部署核对目标版本及安装结束后的新心跳；签名升级还要求 Runtime UP。旧版本在线不等于本次升级成功。
- 原版本、目标版本、完整包摘要分别记录/展示；恢复操作核对原版本新心跳。未记录过目标版本的旧记录保持未知，不能反推成已经验收。
