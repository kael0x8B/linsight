# 可部署算法包

状态：2026-09-09 用户明确批准实施；改造前 Git 基线 `c691cb2`。

## 目标与决策

新增符合契约的算法只上传模型和算法包，不修改 Java、Vue 或 Runtime 主程序。
保留现有模块化单体、Python Runtime、模型池、共享摄像头解码、节点命令、事件与本地自治机制。
算法属于 algorithm 领域，版本复用不可变 PipelineVersion；运行实例仍由 task 管理。

算法包是包含 `algorithm.json` 与 Python 实现的 ZIP。描述文件声明 SDK 版本、算法分类、模型角色、配置 JSON Schema、默认值、资源需求、执行入口和超时。算法包内容按 SHA256 固定；任务固定引用包版本，不随目录发布静默升级。
公共 Runtime 负责模型推理、帧标识、跟踪、事件规则、证据与状态；算法实现运行在独立工作进程，通过有限的 SDK 调用模型能力，返回标准化对象及事件候选。
执行进程有超时、输出大小与退出回收约束，不获得摄像头和平台认证凭据。进程隔离是故障隔离，不宣称是可执行不可信代码的安全沙箱；安装算法属于代码部署权限。

## 配置与部署

平台按包的 Schema 生成表单，复杂控件使用平台已有 ROI、模型和识别库组件。自定义配置使用独立命名空间，不能被旧参数模型丢弃。
模型角色声明能力和格式需求，平台在目标节点解析兼容版本；缺少依赖先安装，就绪后再启动。模型与包分开管理，运行任务均固定精确版本。
包经验证后保存在节点本地，断开平台或重启 Runtime 后仍能加载；平台和本地入口使用同一包和同一执行配置。
模型中心面向明确可部署的版本显示用途、格式和设备适配，保留历史版本入口及原始资产标识。

## 兼容与迁移

现有未引用算法包的 Pipeline 与刷脸配置继续按原协议执行。新字段为可选扩展，旧节点不能接收包任务，必须先升级支持包的 Runtime。
现有 PPE、人脸业务逐步以同一 SDK 提供示例包；保留旧任务回退路径，禁止为迁移覆盖运行配置或自动切换模型。
协议不承诺任意模型二进制即插即用：包必须满足 SDK、模型输入输出及目标运行环境契约。

## 备选方案

只把条件分支拆成源码文件不能满足部署后新增能力；把每个算法做成独立常驻服务会重复摄像头拉流和运维，因此均不采用。

## 回滚与验收

停止使用新包的任务后可选择上一包版本；保留旧包直至无配置引用。平台代码可回到 Git 基线，新增元数据兼容保留。
验收包括：包校验、错误 Schema/哈希/SDK 拒绝、工作进程超时与崩溃、模型兼容及依赖就绪、重复安装、离线重启、旧任务回归，以及平台构建后再上传一个未知算法并由真实模型帧产生标准结果。

实现与 SDK 契约见 [算法包指南](../algorithm-packages/README.md)。当前示例与已上线旧任务并存，旧任务不自动迁移。
