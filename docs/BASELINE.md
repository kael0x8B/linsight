## 2. 当前运行拓扑

```text
Browser :5666
   │ /admin-api
   ▼
Java API :48888
   ├── MySQL :23306  配置、账号、审计与后续业务元数据
   ├── Redis :26379  会话、缓存、分布式状态
   └── MinIO :29000  后续模型、截图、录像与导出文件
```

本地模式直接访问聚合服务，不额外启动网关和注册中心。未来需要多服务拆分时，再启用 Gateway/Nacos，避免在业务模型尚未稳定前增加运维复杂度。

## 5. 当前命名空间

Java 包名、Maven groupId/artifactId 和基座目录已统一为 `com.linsight` / `linsight-*`。后续业务模块必须继续使用该命名空间；Module、Package 与领域边界遵循 [ARCHITECTURE_AND_CODING_GUIDELINES.md](ARCHITECTURE_AND_CODING_GUIDELINES.md)。版本来源表中的上游名称仅用于供应链追溯，不是当前代码命名空间。

## 6. 环境边界

- `.env` 仅供本机使用，已忽略提交；生产环境必须使用独立密钥和凭据。
- 微信/第三方登录在本地配置为不可用占位值，不会主动连接外部平台。
- 当前 MinIO 仅提供服务，还未建立模型、事件证据等正式桶和生命周期策略。
- 当前总览页展示的是基座就绪信息；真实业务指标将在相应模块交付后接入。
